## What changed

`renumber.sh --check` exempted any line containing `Renumbered from`. On #96,
a spec line said "Renumbered from" and also named `upgrades/v0.77.0.md`. The check
read the whole line as history and exited 0, and the pointer was fixed by hand.

- `Renumbered from v<old>` now exempts only that `v<old>` token. Any other
  `<old>` on the same line is listed like any other leftover.
- `<!-- renumber: keep -->` still classifies the whole line.
- `scripts/test-renumber.sh` replays the #96 line; it was seen red first.
- `skills/ship/references/renumber.md` step 3 says to keep pointers off that line.

Renumbered from v0.80.0: main took it with #101 (the route `+delegate` check) while this was in review.
