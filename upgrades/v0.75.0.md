## What changed

On PR #95 a `/code-review --comment` child session went idle having posted
nothing. The container had no `gh`, and the parent could not tell "found
nothing" from "could not post" from "still running" (P57).

- **`skills/review/references/delegated-review.md`** — the child's prompt
  template. First step: post `🔎 Review started … fw-review-start` on the PR
  through the GitHub MCP tools; if that fails, stop and say so. Then review,
  post one review with inline comments, or a "no findings" comment.
- **`delegation-guard.sh` REVIEW family** — a delegated prompt that asks for a
  review (`/code-review`, `/flywheel:review`, or "review" with a PR anchor) and
  lacks `fw-review-start` gets an `ask` naming the template. Ask-only and
  fail-open, like TIER, CONTEXT and FANOUT.
- `/flywheel:review` cites the template from its dispatch step.
