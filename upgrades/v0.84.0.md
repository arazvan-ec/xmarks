## What changed

### Mods are separate plugins, gated (P72 T0)

Claude Code 2.1.289 loads mods: plugins whose `hooks/hooks.json` names a
TypeScript module under `modules`. Flywheel's mods live at `mods/<name>/`, each a
plugin of its own listed in `.claude-plugin/marketplace.json`, so every mod is
opt-in (`/plugin install <name>@xmarks`) and versioned on its own. Some of them
deny tools; none is forced on a flywheel install.

`scripts/check-mods.sh` grades each one: listed in the marketplace, manifest and
`hooks.json` present, at least one `*.test.ts`, `claude plugin validate --strict`
and `claude plugin test` green, and a changed mod's version ahead of the base's
(`SKIP_MOD_BUMP=<reason>` waives it, logged). No mod ships in this release; the
gate reports `no mods` until T1 lands.

Nothing to do in a repo that uses flywheel: the vendored install is unchanged.
