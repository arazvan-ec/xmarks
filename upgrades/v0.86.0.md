## What changed

### A lesson's open work lands in the backlog (P74)

`/flywheel:compound` used to write lessons whose open work ("a follow-up
should…") stayed as prose in `LEARNINGS.md`, where nobody who schedules work
reads it. Now a lesson that leaves work open gets a row in the backlog
(`docs/research/improvement-proposals.md`, or `.claude/flywheel/BACKLOG.md` in a
repo without one) and says so in its metadata line: `followup=<one line>;
backlog=P<n>`. `skills/compound/references/followups.md` has the steps.

`scripts/check-followups.sh` checks it in this repo's CI: every `followup=`
must name a `backlog=P<n>` whose `| P<n> |` row exists. A ledger with no
`followup=` passes, so nothing changes for entries written before this.
