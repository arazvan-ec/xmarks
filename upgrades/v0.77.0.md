## What changed

The pre-push sweep was a loop people pasted by hand, and each copy dropped a
different detail (P60).

- **`scripts/sweep.sh [<base-ref>]`** (default `origin/main`) runs
  `claude plugin validate . --strict` when the CLI is present, or says `SKIPPED`
  when it is absent. It then runs every `run: bash scripts/check-*.sh` step in
  `validate-plugins.yml`, with its arguments read from the workflow and
  `${{ github.base_ref }}` resolved to the base ref, and finally every
  `scripts/test-*.sh`. The scripts run one at a time, each with its own `TMPDIR`.
  Each prints `PASS`/`FAIL <name>`, read from the exit code. A failure shows the
  last 20 lines of that script's output. The sweep ends with `N/N passed` and
  exits 1 if any script failed. `--list` prints the commands and runs nothing.
- **Plans can cite `bash scripts/sweep.sh`**, because it is now in
  `task-closure-allow.txt`. `check-task-closure.sh` sets
  `FW_TASK_CLOSURE_ACTIVE=1` on the checks it runs. A sweep that finds the marker
  skips `check-task-closure.sh` and says `SKIPPED`, so it never re-grades every
  plan from inside one task's 300s timeout.
- The "Run before pushing" line in CLAUDE.md is now `bash scripts/sweep.sh`.
