## What changed

The toolbar rule lived in one repo's CLAUDE.md, loaded once and observed by
nothing; a session with a 4-task plan answered several turns without it, and
told once, dropped it again on the next note (P56).

- **`scripts/toolbar.sh remind`** (`UserPromptSubmit`): while a plan this branch
  touches has a task with no transition line, injects the toolbar format and the
  live count — `slug done/total (open: T3, T4)` — every prompt.
- **`scripts/toolbar.sh stop`** (`Stop`): blocks (exit 2) a final reply whose
  first non-empty line is not `<🟢|⏸️|🔴|🏁> <n>/<N> …`, or whose `N` is not an
  open plan's total. Reads `last_assistant_message`, falling back to the
  transcript. `stop_hook_active` never re-traps; anything unreadable is a no-op.
- **Scope:** only the final reply of each turn. Mid-turn notes are exempt, by
  the owner's decision. A list that is not a plan is not seen by the hook.
- Wired in `hooks/hooks.json` and in `install-vendored.sh` (vendored repos get
  both hooks on the next install or auto-update).
