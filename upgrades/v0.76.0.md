## What changed

Two steps went wrong by hand on 2026-09-23 (P58).

- **`fixture-scratch.sh --executor-prompt`** keeps the workdir and prints the
  eval prompt inside the executor preamble, in one call: read the skill's
  `SKILL.md`, touch only the workdir, report briefly. The template lives in the
  tool, so there is no copy to drift.
- **`--print-prompt` without `--keep` or `--into` now exits 2.** It printed a
  workdir that the teardown deletes. `--keep` and `--print-prompt` as two
  calls sent two executors to a path that did not exist. The work and verify
  eval READMEs say which flag each arm uses (baseline:
  `--keep --print-prompt`).
- **`skills/review/references/answering-review.md`**, cited from
  `/flywheel:review`: reproduce each finding red, fix them together, reply on
  every thread naming the commit before the push, then push and resolve.
- A ledger `pattern` entry records the practice. A template needs a failure
  behind it, a check that it was used, and a pointer rather than a copy.
