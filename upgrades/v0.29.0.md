## What changed

- **CLAUDE.md — "Dev-loop discipline: flywheel develops flywheel"**: every
  plugin feature runs the loop on this repo regardless of size ("it's a small
  change" is the excuse `/flywheel:work` bans); scripts are test-first;
  behavior changes to `work`/`verify`/`process`/`run` become eval-gated when
  P22 phase 2 lands.
- **New `scripts/check-test-pairing.sh`** (developed red→green: its test
  existed and failed before it did): diffs the PR against its base and fails
  if any `scripts/<name>.sh` changed without its paired
  `scripts/test-<name>.sh` — add, update or delete together.
  `SKIP_TEST_PAIRING=1` skips with a logged notice, never silently.
- **`scripts/test-check-test-pairing.sh`**: 7 scenarios (docs-only, script
  alone, script+test, new script, test-only, deletions, escape hatch) against
  a temp git repo.
- **CI (`validate-plugins.yml`)**: pairing gate runs on every PR
  (full-history checkout, diff vs `origin/<base>`); the gate's own test joins
  the suite.
- **Docs**: P22 recorded in the proposals backlog + decision log; phase 2
  (behavioral skill evals as manual release gates for `verify`/`work` and
  `process`/`run`) left open.
