## What changed

- **New `scripts/check-description-budget.sh`** (developed red→green: its test
  existed and failed with exit 127 before the gate did): sums the frontmatter
  `description` **value** length across `skills/*/SKILL.md` and fails above the
  committed budget. On failure it prints the per-skill breakdown largest-first,
  so the diff says *which* skill grew rather than just "over budget".
  `SKIP_DESCRIPTION_BUDGET=1` skips with a logged notice, never silently;
  `FW_DESC_BUDGET` overrides the budget for probes.
- **`scripts/description-budget.txt` = 3600.** The budget lives in its own file
  rather than inside the script for a specific reason: raising it is then a
  one-line reviewable diff that does **not** trip the script/test pairing gate.
  Headroom over the current 3301 is about one average description — a single new
  skill lands free, a second requires a deliberate bump. The tight threshold
  *is* the ratchet.
- **Malformed input fails loudly** (exit 2, naming the skill): no frontmatter
  `description`, an empty value, or a YAML folded/block scalar
  (`description: >` / `|`). A parser that quietly counted those as 0 would let
  the budget be evaded by making a description unparseable.
- **Only the leading frontmatter counts** — a `description:` line in the skill
  body is prose and is never summed.
- **`scripts/test-check-description-budget.sh`**: 8 scenarios against synthetic
  skill trees in `mktemp -d` (under budget, over budget, breakdown ordering,
  body-level `description:` ignored, missing value, empty/`>`/`|` values,
  `FW_DESC_BUDGET` override both directions, logged escape).
- **CI (`validate-plugins.yml`)**: the gate runs on every push and PR, and the
  gate's own test joins the suite.
- **Spec**: `.claude/flywheel/specs/p24-description-budget.md` with a
  machine-checkable success metric.

## Note on the measurement

Two numbers describe the same v0.30.0 trim, measured differently: 5,441 → 4,246
chars counting the whole `description:` line (the figure in the 2026-07-30 audit)
and **3,301 chars counting values only**, which is what this gate sums — the key
prefix is not something an author controls. Compare like with like when reading
either figure.
