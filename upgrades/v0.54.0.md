## What changed

- **The duty is ungated.** `skills/work/SKILL.md` now says the transition line is
  appended **every run, in a cycle or standalone**. The precondition is replaced
  with its opposite rather than simply deleted: a silent condition is what caused
  this, so the absence of one is not enough.
- **`scripts/check-telemetry.sh`** — a CI gate with two halves. *Conformance*:
  every `.claude/flywheel/runs/**/*.jsonl` line carries the contract's keys and no
  `tokens` field. *Coverage*: every spec slug has telemetry unless the baseline
  exempts it.
- **The baseline lists what is EXEMPT, not what is expected.** A new spec is
  covered by default, so forgetting one fails the gate instead of passing
  quietly — the rule this replaces needed someone to remember, and for
  twenty-nine cycles nobody did. An exemption with no reason is unusable input,
  because an exemption is a debt and the reason is what makes it payable.
- **The exemption covers shape, never the `tokens` ban.** A baselined slug's file
  predates the contract, so its shape is reported as a note rather than a
  failure; a `tokens` field fails regardless, since P18 governs what may enter
  the ledger at all.
- **`scripts/telemetry-baseline.txt`** opens with 29 entries — every cycle in the
  repo's history. Nothing was backfilled: inventing telemetry for a cycle nobody
  measured is exactly the fabricated evidence P18 exists to keep out, so each one
  stays visibly unmeasured until a real cycle pays it down.

The fix proves itself: this release's own cycle is the first conforming run in
the repo, and reading it back exercises every honesty rule P40a shipped one day
earlier — `bytes_in` and `tool_calls` report UNMEASURED rather than zero (neither
is observable from git after the fact, so both were omitted instead of guessed),
and `elapsed_s` reports PARTIAL 4 of 5 because the first transition has no
predecessor.
