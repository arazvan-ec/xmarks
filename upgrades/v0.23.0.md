## What changed

- **`/flywheel:process`** (`skills/process/SKILL.md`) — the prescriptive
  "Multi-runtime profiles" section (v0.22.0) is replaced by **"Repo
  extensions"**: cross-cutting intervention patterns are repo-owned documents
  at `.claude/flywheel/extensions/<name>.md` (name, applies-to, added
  inputs/conventions, guardrails, own Improvement log). Contracts declare
  `extensions: [<name>, …]` in frontmatter instead of duplicating the
  convention's text; when the owner asks for a cross-cutting pattern, the
  deliverable is an extension doc.
- **`/flywheel:run`** (`skills/run/SKILL.md`) — loads every extension the
  contract declares and honors it for the whole run (added inputs like
  `profile=<id>`, namespacing, isolation, telemetry naming, capability
  fallbacks). Extensions never override a contract's Rules, Output schema, or
  Guardrails. Profile-specific wording removed.

## Why

The plugin ships the *mechanism*; the *pattern* belongs to the repo, versioned
and matured next to the data it governs (owner direction, 2026-07-27). First
extension in the wild: `keep`'s `.claude/flywheel/extensions/profiles.md`.
