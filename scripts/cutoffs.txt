# flywheel — where a gate's cutoff instant is declared (P54b).
#
# A cutoff decides which half of the corpus a rule binds. Before this file each
# one was a date literal inside the gate that used it, behind its own env var,
# so two that were placed by ONE decision could drift apart and nothing said
# they were supposed to match.
#
# Format: <name> <ISO instant> <reason>. The reason is not optional — a bare
# date is what made the coupling invisible in the first place.
#
# Moving a value here is a POLICY change, never a refactor: everything before a
# cutoff is forgiven permanently and nothing may be backfilled to undo it (P18).
# scripts/test-fw_cutoffs.sh pins all three against their pre-extraction values,
# so a move has to be argued in the row and in that test together.
#
# Each gate still honours its own env var, which wins over the row.
